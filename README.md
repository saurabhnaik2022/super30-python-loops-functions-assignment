## Assignment Description
20 Python programs that practise `for` loops, `while` loops, nested loops and functions,
from a simple number analyzer up to a menu-driven Student Registration System.
Each file starts with a comment saying *why* that loop/function was chosen.

## Setup & Run
1. Install Python 3.8+ (`python --version` to check).
2. Clone the repo:
   ```
   git clone https://github.com/saurabhnaik2022/super30-python-loops-functions-assignment.git
   cd super30-python-loops-functions-assignment
   ```
3. Run any program:
   ```
   python 01_number_analyzer.py
   ```
   (use `python3` on macOS/Linux)
